系列 - What Every Programmer Should Know

程序员的通识，两条线。

一条是把一篇经典论文完整读透——Drepper 的《What Every Programmer Should Know About Memory》，四篇中文全译。

一条是从零把计算机搭一遍——自己整理的「计算机组成」系列，从布尔逻辑一路做到 ALU。

一、What Every Programmer Should Know About Memory

Ulrich Drepper 的《What Every Programmer Should Know About Memory》全文中文翻译。

这大概是程序员读过的最值得的一篇「内存」文章——它不讲某个 API 怎么用，而是把一台现代计算机的内存子系统从 DRAM 颗粒一路拆到 CPU 的 L1i/L1d，从虚拟内存页表一直讲到 NUMA 的内存策略，最后落到「程序开发者到底能做什么」这个最实际的问题上。

四篇按章节顺序读：先认识硬件（RAM 的类型与访问时延、CPU cache 的工作方式），再补上操作系统这一层（虚拟内存、NUMA），然后是全篇最实用的第 6 章（写给程序员的建议），最后是工具与还没到来的技术（怎么测量、怎么优化，以及事务内存这类未来）。

只读一篇的话，建议直接看第 03 篇《程序开发者能做些什么》——那是全篇的落点，前两篇是它的铺垫。

#篇目这一篇讲什么
01What Every Programmer Should Know About Memory (1)第 1–3 章：引言、现代商业硬件（RAM 类型、DRAM 访问细节）、CPU cache 的工作方式与实现细节
02What Every Programmer Should Know About Memory (2)第 4–5 章：虚拟内存（地址转换、多级页表、优化页表访问）与 NUMA 硬件和操作系统支援
03What Every Programmer Should Know About Memory (3)第 6 章：程序开发者能做些什么——cache 访问、预取、多线程优化、NUMA 编程
04What Every Programmer Should Know About Memory (4)第 7–8 章：内存性能工具（剖析、模拟、测量、页面错误优化）与即将到来的技术（事务内存、延迟、向量操作）

英文原文：What Every Programmer Should Know About Memory（Ulrich Drepper, Red Hat, 2007）

二、What Every Programmer Should Know Computer

自己整理的计算机组成系列，按自己的理解串起来的一条线。

不是某本书的翻译，而是从「计算机到底由什么组成」这件事的最底层开始往上搭：先讲机器是怎么来的（从莱布尼茨的机械计算器、差分机与分析机，到马克 1 号、ENIAC 与冯·诺依曼架构），再把「电怎么变成 0 和 1」讲透（布尔逻辑与晶体管门电路），然后是二进制的表示与运算，接着用加法器把门电路拼成真正能用的部件（半加器、全加器、多位全加器），最后是译码器、编码器、多路复用器这些组合逻辑，以及 CPU 里真正干活的 ALU。

这条线是第一条线的地基——想理解 cache 和内存为什么长成那样，得先知道数据在里面是怎么被表示、怎么被算出来的。

#篇目这一篇讲什么
05What Every Programmer Should Know Computer 001早期计算机与现代计算机（机械计算器、差分机与分析机、马克 1 号、ENIAC、冯·诺依曼架构）、布尔逻辑与晶体管门电路、二进制的表示与运算
06What Every Programmer Should Know Computer 002加法器（半加器、全加器、多位全加器）、Enabler、Decoder、Encoder、Multiplexer
07What Every Programmer Should Know Computer 003（未完待续）ALU（算术逻辑单元）：CPU 里真正干活的部件
